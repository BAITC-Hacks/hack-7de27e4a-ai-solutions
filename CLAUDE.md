# CLAUDE.md

Все правила проекта — в **`AGENTS.md`**, читать его первым. Ниже только то, что специфично
для сессий Claude.

## Контекст

Основной кодовый агент в этой команде — **Codex**: он пишет большую часть кода в трёх
параллельных потоках. Claude подключается точечно, поэтому ценность выше всего там, где
нужно «сделать правильно один раз»:

- **ревью** результата Codex, особенно стык «заявленная логика ↔ фактическая реализация»
  (в разбалловке жюри это отдельный критерий);
- **red-team проход** перед feature freeze — `docs/WORKSTREAMS.md` раздел E;
- **README и документация** — 25 из 100 баллов, столько же, сколько вся техническая реализация;
- **спеки и prompt'ы** для Codex-задач;
- **проверка утверждений о данных** — цифры берём из `data/source/`, а не из презентаций.

## Правила для Claude

- **Не писать код в чужих каталогах.** Границы те же, что в `AGENTS.md`.
- **Проверять факты о датасете скриптом**, а не пересказывать документы. В `docs/DATASET.md`
  всё уже сверено с `data/source/`; если находишь расхождение — чинить документ, а не данные.
- **Не заявлять в README функции, которых нет в коде.** Перед правкой README — прочитать код.
- **При ревью возвращать дефекты, а не переписывать чужую зону.** Исправления остаются у
  владельца каталога.
- Отвечать по-русски; код, идентификаторы и коммиты — по-английски.

## Что уже проверено (не перепроверять без причины)

Объёмы файлов, распределения статусов и языков, число профилей с `career_goal`, replay-история
E0028 и его критичные навыки — всё сверено с реальным датасетом и записано в `docs/DATASET.md`.
